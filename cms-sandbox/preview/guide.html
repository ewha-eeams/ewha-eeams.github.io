자료 관리로 돌아가기

편집·저장 → 반영 준비 → 홈페이지에 반영
Save는 편집 내용 저장입니다. 홈페이지는 마지막 ‘홈페이지에 반영’ 버튼을 눌러야 바뀝니다.

  1. 자료를 편집하고 저장합니다

    Dock의 EEAMS 관리를 열고 관리할 자료의 편집 ↗을 누릅니다. 새 탭에서 공연명을 선택하거나 항목 이름을 펼쳐 수정하고, 위쪽 Save(저장)를 눌러 저장 완료를 확인합니다.

    편집 화면은 기존 GitHub 계정으로 로그인합니다. 예약용 PIN과는 별개입니다.

  2. 홈페이지에 반영할 내용을 확인합니다

    왼쪽 메뉴에서 자료를 다시 선택하지 말고 먼저 열어 둔 관리 탭으로 돌아와 해당 자료의 홈페이지에 반영…을 누릅니다. 수정 내용은 필요할 때 펼쳐 볼 수 있습니다.

    공연은 반영할 공연을 선택합니다. 참여자·특강/워크숍·연구는 해당 종류에 저장된 수정 전체가 함께 반영됩니다. 원치 않는 수정이 있으면 편집 화면에서 먼저 정리하세요.

  3. 반영 준비를 누릅니다

    파일과 홈페이지 표시, 반영 후 저장 연결을 자동으로 확인합니다. 검사가 끝나면 최종 대상 목록이 나타납니다. 이 단계에서는 홈페이지가 바뀌지 않습니다.

    필요하면 게시 전 보기와 확인 기록을 펼쳐 화면과 검사 결과를 확인하세요. 미리보기는 필수 단계가 아닙니다.

  4. 마지막 확인 후 홈페이지에 반영합니다

    대상 목록을 확인하고 위 내용을 홈페이지에 반영합니다에 체크한 뒤 홈페이지에 반영을 누릅니다.

    완료 표시가 나오면 홈페이지에서 보기로 확인합니다. 표시되기까지 잠시 걸릴 수 있습니다. 다음 수정을 시작할 때는 편집 화면도 새로 불러오세요.

필요할 때 확인하세요

  • 수정 내용이 없음: 저장하지 않았거나 홈페이지와 같은 내용입니다. Save 완료를 확인한 뒤 ‘최신 내용 불러오기’를 누르세요.
  • 반영 준비 중 자료가 달라짐: 다른 저장이 있었을 수 있습니다. 최신 내용을 다시 불러와 확인하세요.
  • 반영 버튼을 누른 뒤 연결이 끊김: 새 요청을 반복하지 말고 결과 다시 확인을 누르세요. 같은 화면을 새로고침해도 이전 요청의 결과를 확인합니다.
  • 첨부 자료: 새 파일은 5MB 이하로 준비합니다. 3~5MB는 자료 업로드 안내의 별도 경로를 사용합니다. 기존 자료는 유지합니다.

이 관리 도구는 현재 이 Mac에서 사용합니다. 앱을 닫거나 Mac을 꺼도 공개된 홈페이지는 유지됩니다. 예약 등록·취소는 이 도구에서 다루지 않습니다.
