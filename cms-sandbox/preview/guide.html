EEAMS 자료 관리

사용 안내

자료 수정부터 게시까지의 순서입니다.

콘텐츠 관리

편집·저장 → 미리보기 → 변경 확인 → 사본 검증 → 최종 확인·게시

Save는 초안 저장입니다. 홈페이지는 마지막 게시 확인 버튼을 눌러야 바뀝니다. 예약 등록·취소는 이 관리 도구에서 다루지 않습니다.

  1. 관리 앱을 엽니다

    Dock의 EEAMS 관리를 누르고, 관리할 자료를 고릅니다. 앱과 웹 관리 화면 양쪽에 사용 안내가 있습니다.

    관리 화면의 게시 연결에 ‘최종 확인 후 게시’가 보이는지 확인하세요. 이 Mac과 인터넷 연결이 필요합니다.

  2. 편집하고 Save를 누릅니다

    자료 목록에서 편집 ↗을 누릅니다. 새 입력 화면에서 수정한 뒤 Save를 누르고 저장 완료를 확인합니다. 새 공연은 새 공연 추가로 시작합니다.

    입력 화면은 Pages CMS입니다. 로그인이 필요하면 기존 GitHub 계정을 사용합니다. 스튜디오 예약용 PIN과는 별개입니다.

  3. 홈페이지에 보일 모습을 확인합니다

    관리 탭으로 돌아와 해당 자료의 미리보기 → 저장본 새로고침을 누릅니다. 컴퓨터 / 휴대폰으로 글·순서·자료 링크를 살펴봅니다.

    입력 화면과 관리 화면은 별도 탭입니다. Save 후 미리보기를 새로 불러와야 최신 내용을 읽습니다.

  4. 변경 전후와 범위를 확인합니다

    변경 확인 →에서 현재 공개 내용과 저장한 초안을 비교합니다.

    공연은 게시할 공연을 선택합니다. 참여자·특강/워크숍·연구는 해당 자료 종류의 미반영 변경 전체가 대상입니다. 원치 않는 수정이 섞여 있으면 편집 화면에서 먼저 정리하세요.

  5. 사본에서 게시와 기준 갱신을 검증합니다

    공연: ‘선택한 변경으로 반영 준비’ → 범위 확인 → 확인란 → ‘사본에 반영 시험’ → ‘게시·CMS 동기화 사본 검증’.

    나머지 자료: ‘변경 전체로 사본 반영 준비’ → 범위 확인 → 확인란 → ‘게시·동기화 사본 검증’.

    이 단계까지는 실제 홈페이지에 게시되지 않습니다. 결과 미리보기가 예상과 같은지 확인하세요.

  6. 마지막 확인 후 게시합니다

    공연: ‘실제 게시 연결 확인’ → 공개할 공연 목록 확인 → 마지막 확인란 → 확인한 공연 게시.

    나머지 자료: ‘공개 반영 후보 확인’ → 변경 전체와 파일 범위 확인 → 마지막 확인란 → 확인한 내용 공개 반영.

    완료 표시와 CMS 기준 갱신을 확인하고 공개 결과를 엽니다. 공개 웹페이지에 새 내용이 나타나기까지 시간이 필요할 수 있으니, 잠시 후 새로고침해 확인합니다.

    게시 후 다음 수정을 시작할 때는 열어둔 CMS 편집 화면도 새로 불러오세요.

헷갈릴 때

  • 변경 0건: 아직 Save하지 않았거나 이미 공개 내용과 같은 상태입니다. Save 상태를 확인하고 새로 불러옵니다.
  • 저장본·기준이 달라졌다는 안내: 다른 저장이 있었을 수 있습니다. 최신 입력 화면과 미리보기를 다시 불러와 비교합니다.
  • 게시 중 응답이 끊겼을 때: 같은 화면의 게시 상태 확인을 먼저 누릅니다. 결과 확인 전에 새 게시를 반복하지 않습니다.
  • 큰 PDF: 관리 시작 화면의 자료 업로드 안내를 이용합니다. 3 MB가 넘는 파일은 그 안내의 별도 경로를 사용합니다.

앱을 닫거나 Mac을 꺼도 이미 공개된 홈페이지는 유지됩니다. 관리 도구는 현재 이 Mac의 설정을 사용하므로 다른 Mac으로 옮길 때는 별도 연결 준비가 필요합니다.
